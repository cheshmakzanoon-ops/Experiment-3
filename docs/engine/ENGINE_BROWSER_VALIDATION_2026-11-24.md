`idbKv`, and `FrameBufferPool` modules. Every test gets a fresh Playwright browser
context and a routed localhost document. Native IndexedDB requests, transactions,
structured cloning, version-change events, and a dedicated browser Worker are
used. No existing browser profile, personal saved game, resource asset, or
authored scene is opened or changed.

| Case | Intended native behavior checked | Local execution |
| --- | --- | --- |
| Replay session isolation | Independently cloned typed arrays, separate session keys, disposal removes only the owning session, terminal/idempotent disposal | Blocked before launch |
