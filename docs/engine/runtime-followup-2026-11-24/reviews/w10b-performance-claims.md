## Equivalence is finite evidence

W07E's three actual production Simulation scenarios each run **1,200 ticks / ten simulated seconds**, with **1,201 packed-frame and public dynamic-state observations** and **11 weather/surface/terrain checkpoints**. Recorded exact trace byte counts are formula **140,100,864**, wet motorcycle **234,218,818**, motocross **242,861,634**, totaling **617,181,316**. This total includes 28,824 bytes of record-length framing. The count and per-scenario source/hash receipts agree; this audit did not regenerate those traces.

The capture uses `writeFrame(frame, 0, 0)` in both versions and includes the same zero timing/dropped defaults. It serializes the specified exposed car/race/AI/offroad state, preserving numeric bits and graph links. It excludes inaccessible `#private` fields, shared authored/static definitions, contact-BVH internals and collision scratch. Surface/terrain state is sampled every 120 ticks rather than every tick. Approve “these captured traces matched exactly,” never “all gameplay/numeric behavior is proven identical for all inputs.” The original W07 traces belong to B/M, not a new F9 trace execution; W08F separately retains final-guard integer-buffer evidence and malformed-input rejection.

Native W08E receipts support **1,025 wrappers, three groups/draws/GPU textures**, zero CPU/GPU pixel differences against independent references for those groups, and **six** Festival cycles with texture/geometry/program counts **5/6/7→1/2/4**. They do not show a baseline/current GPU allocation speedup or every game image. W06A supports zero canceled future-window peaks and zero PCM differences across **96,000 channel samples per one-second stereo replacement comparison**. These are native API correctness observations, not physical device or latency measurements.
