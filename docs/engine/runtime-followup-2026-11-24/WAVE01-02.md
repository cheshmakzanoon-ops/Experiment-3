### Recording clock and bounded ghosts

Telemetry now compares the rewind receipt against stored session time in the Float32 domain and resets tick deduplication after removing the discarded branch. A full chronological snapshot copies the same data in at most two spans. The committed regression covers wrapped-tail truncation, another wrap after resume, tick reuse and independently owned snapshot bytes.

Ghost capture uses the existing valid lap interval and a derived sample cap, releases unusable/ineligible laps, validates finite pose/metadata fields and validates the completed record before publishing it. Ordinary accepted samples and crossing-pose ownership remain covered. This changes validation behavior while retaining version-1 record shape.

### Discrete network shifts and archive compatibility

Live command shifts are separate next-update edges, consumed once and cleared when AI takes ownership. Invalid client samples cannot revive the previous shift. Tags 0/4 keep persistent-shift semantics for old archived controls; explicit tag 5 represents the new edge. The journal bound increases to account for that entry. The tests cover redundant/late commands, loss, repeated identical intent, mode handoff, malformed tags and deterministic record replay.

This is an intentional journal extension, so the historical reconstruction does not describe all formats as unchanged.

### Host failure and transport ownership

Host failure detaches active ownership before callbacks and attempts independent cleanup despite secondary errors. Rumble stops directly on pause/suspension. The host reports the original failure and does not let reentrant disposal terminate the detached worker twice.

The server captures each car once per boundary, creates independent encoded recipient packets before sends, and bounds synchronous reentry to one follow-up batch. It retires peer ownership before close callbacks, isolates send/close failures and keeps a bounded tail of original transport errors. Tests preserve normal packet bytes, recipient flags, buffer independence and future contacts/events, while allowing physics/encoding errors to reach their supervisor.

### Ordered controller edges

Controller shifts now use an acknowledged staged pulse plus a bounded FIFO reserve. Rapid key and gamepad events retain accepted order; held repeats/widget keys are excluded and reset/device ownership boundaries clear stale intent. Newest overflow is dropped at the existing 32-edge bound. The controller does not consume a pulse merely because controls were read twice.
